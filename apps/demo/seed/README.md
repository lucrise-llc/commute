# Storefront

A small store that the Commute demo changes with 20 agents at the same time.

- `src/cart`: prices, discounts, and the cart badge
- `src/search`: the search index and suggestions
- `src/catalog`: the products
- `src/i18n`: the English strings
- `src/routes.mjs`: the pages of the store
- `docs`: how to set up and use the store

Run `node scripts/check.mjs <area>` to check one area.
